# 台词活化

一个用于打磨人物对白与旁白的 AI 技能。它根据人物、场景和节奏修复生硬台词，并尽量保留原有剧情、事实和人物决定；已经自然的文字可以保持原样。

## 使用

将本目录作为技能安装到支持 `SKILL.md` 格式的助手中，然后提供台词或旁白，并说明人物关系、场景和希望保留的语气。例如：

> 用台词活化处理这段对白。两人是多年未见的兄妹，哥哥克制，妹妹急躁。不要改变事件和决定。

助手应先阅读 `SKILL.md`，并按需参考 `references/`。不同平台的安装路径和加载方式可能不同。

## 包含内容

- `SKILL.md`：技能说明与工作方法
- `references/`：对白、旁白和风格参考

生成结果仍需由作者结合角色与剧情审阅。
