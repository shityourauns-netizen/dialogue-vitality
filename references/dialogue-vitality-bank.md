# 台词活性语料库（Dialogue Vitality Bank）

SKILL.md 的扩展资源。需要更细的语气词选择、停顿模板、角色分化或更多 before/after 时读取本文件。所有示例为中文台词。

---

## 一、语气词情绪寄存器

按情绪/语气挑词，少量贴情境。**切忌每句都加**——那是另一种 AI 味。

| 情绪/语气 | 推荐词 | 用法示例 |
|---|---|---|
| 迟疑·思考 | 嗯、这个、那个、其实吧、怎么说呢、就是说 | "那个……我想问，你昨天去哪了？" |
| 软化·商量 | 吧、嘛、呢、好吗、行不、成不 | "你就吃一口嘛。""这事，再想想吧？" |
| 确认·强调 | 啊、呀、啦、呗、嘛、喏 | "早说啊！""反正都这样了呗。" |
| 不耐·轻微嫌弃 | 切、嘁、哼、哟、嚯 | "切，又来了。""哟，您可真忙。" |
| 无奈·叹息 | 唉、哎、嗨、罢了 | "唉，随你吧。""嗨，说这些没用。" |
| 惊讶·意外 | 咦、哈、啊、哇、我的天 | "咦，你也在？""我的天，这都行？" |
| 委屈·带着哭 | 呜、呀、啊（拖长） | "我……我哪有——""你凶什么呀。" |
| 撒娇·亲昵 | 嘛、啦、呀、呗、人家 | "陪我去嘛～""人家不想走啦。" |
| 质疑·反问前置 | 啊、怎么、凭什么 | "啊？你再说一遍？""凭什么啊？" |
| 顿悟·接话 | 哦、噢、懂了、原来 | "哦——你早说啊。""噢，是这样。" |

**搭配禁忌**：同一句里别堆两个强语气词（"哎哟哇"显假）；叹词放句首或句尾最自然，句中慎用。

## 二、停顿与延迟模式库（治"没有延迟"）

真人说话不是一气呵成的。用以下手段制造"延迟感"，但要在语义允许处。

| 模式 | 写法 | 适用 |
|---|---|---|
| 卡壳 | "我……我不知道。" | 慌乱、被问住 |
| 欲言又止 | "其实我——算了。" | 犹豫、隐藏 |
| 思考填空 | "那个，怎么说呢，就是……" | 组织语言 |
| 重复词 | "这个这个……""你你你别——" | 急、慌 |
| 半句收住 | "我是说——""没什么。" | 改口、咽回去 |
| 被截断 | "我跟你讲——" / "别讲了。" | 互动毛刺 |
| 长停顿暗示 | "（良久）……你走吧。" | 沉重、决绝 |
| 填充启动 | "其实吧，""说真的，""不瞒你说，" | 开场铺垫 |

**中文标点约定**：用全角省略号"……"表停顿/迟疑；用"——"表打断或话锋一转；不要混用半角"..."或".."。干净稿里只用这两种破折类标点承载停顿，**不写** `[停顿2秒]` 这类舞台说明（那属于备注区块）。

## 三、情绪载体手法

情绪不是靠"她生气地说"这种标签，而是靠台词本身。

| 情绪 | 台词手法 | 示例 |
|---|---|---|
| 愤怒 | 短句连发、脏话/口头禅、质问 | "你疯了？谁让你动的？说啊！" |
| 委屈 | 重复、碎碎念、尾音上扬 | "我明明……我就是……你从来都不信我。" |
| 慌张 | 语序乱、重复、半句 | "不是我不是我，我刚、刚没看见——" |
| 失落 | 长句拖尾、低能量词 | "行吧。反正……也没人在乎。" |
| 激动/喜 | 短促、叠词、感叹 | "真的？！真的真的？！" |
| 不屑 | 轻飘、反问、短 | "就这？我还以为多大事。" |
| 紧张 | 咽字、改口、小声 | "我……那个……没、没什么。" |
| 撒谎 | 过于流畅或过于停顿 | "我昨天一直在家。（停顿）看书。" |

## 四、角色分化模板

每人填一份，避免全员同口吻。改写前先给主要角色定调。

```
角色名：___
- 句长偏好：长句慢悠悠 / 短句干脆 / 忽长忽短
- 词汇癖：爱用文言词 / 爱用网络语 / 爱用俗语 / 书面腔
- 口头禅：___（如"我跟你说""要死啊""说白了"）
- 逻辑习惯：绕弯子 / 直来直去 / 先否定再解释
- 情绪表达：外放骂人 / 内收沉默 / 用反话 / 碎碎念
- 对谁变调：对上级___，对晚辈___，对敌人___
```

**示例**：老陈（疲惫老兵）——句短、爱叹气、词汇朴素、口头禅"唉，造孽"、情绪内收、对年轻人话少。爷爷（山村老者）——慢、带气声、用"娃""实在"等词、每句后有停顿。

## 五、AI 死台词模式详表（含更多 before/after）

### 模式 A：完整句癖 → 碎片/省略
> 原：我知道你是为了我好，但是我现在还没有准备好接受这段感情。
> 改：我知道你为我好。可我……还没准备好。

### 模式 B：信息报告癖 → 随口一句
> 原：根据气象台发布的数据，明天的降雨概率达到了百分之八十，建议减少外出。
> 改：气象台说了，明天八成要下，少往外跑。

### 模式 C：全员同口吻 → 分化
> 原（小孩 & 将军 同款）：我明白了，我会按照计划执行的。
> 改（小孩）：哦！知道啦，我这就去！
> 改（将军）：……明白了。照计划办。

### 模式 D：逻辑过顺 → 加毛刺
> 原：我们先去超市买菜，然后回家做饭，吃完饭再看电影。
> 改：先去超市吧——哎不对，你冰箱里还有菜呢。算了，随便。

### 模式 E：说明性台词 → 藏信息
> 原：你知道吗，我们家族世代都是守护这把剑的，它已经有三百年历史了。
> 改：这剑……我爷爷的爷爷就在守着了。（伸手摸剑身）

### 模式 F：语病/书面腔 → 口语
> 原：我对于你的这个提议，是持着一种谨慎的态度的。
> 改：你这提议，我得谨慎点。
> 原：他进行了一次长时间的思考。
> 改：他想了老半天。

### 模式 G：伪口语（加了词但句还是书面）
> 原：这件事情嘛，确实是需要我们去进行一个深入的思考的呀。
> 改：这事儿吧，真得好好想想。

## 六、常见语病类型与改法

| 类型 | 病例句 | 改法 |
|---|---|---|
| 赘余"进行/加以" | 进行一个思考 | 想想 |
| "对于…来说"腔 | 对于这件事来说 | 这事 |
| "在…方面"腔 | 在学习方面 | 学习上 |
| 半文半白 | 此事宜缓图之 | 这事先放放 |
| 主谓搭配错 | 他的心情很繁重 | 他心情很沉重 |
| 语序乱 | 我昨天把书在桌上放了 | 我昨天把书放桌上了 |
| 双重否定绕 | 不得不说不是没有道理 | 说的倒也在理 |
| 中西混杂 | 这个 case 很 tricky | 这事儿挺棘手 |

## 七、使用注意

- 本库是"素材箱"，不是"清单"——按场景挑，但本技能 v2 的"表演融合"模式下，填充词/话语标记/犹豫标记是**主料要铺满**，不是点缀；只有原稿本就鲜活（真人作者写的活台词）时才收手、只做轻量语病修复。
- **全员别一个模板**：每人有自己的口头禅与节奏配比（见第四节模板），否则又回到"全员同口吻"。
- 历史/古装语境：语气词换"罢了、岂、焉、哼"等，但保持口语感，别写成文言。
- 方言角色：可用少量方言词点睛，但保证主流读者能懂，不通篇方言。
- 与 [style-fusion-and-memes.md](style-fusion-and-memes.md) 配合：四风格技术表与网梗库在那边。
- **抑扬顿挫是本技能的节奏总纲**：每段对白 抑/扬/顿/挫 必须交替，单调=死。扬≠金句、顿≠糊涂（详见 SKILL.md「节奏总纲」与 style-fusion-and-memes.md「五、抑扬顿挫 × 四风格」）。

## 八、抑扬顿挫速查

| 维度 | 一句话 | 台词信号 |
|---|---|---|
| 抑（低·收） | 低、收、沉 | 短句、低能量、尾音拖沉、欲言又止、反话 |
| 扬（高·放） | 高、放、炸 | 感叹号、短促连发、反问、破音、爆发 |
| 顿（停·断） | 停、断、空 | 省略号、半句收住、被截、长停顿、静场 |
| 挫（转·折） | 转、折、反 | "不是，我是说…"、突然拐弯、反话、反转 |

交替 = 活，单调 = 死。扬是情绪音量之放而非金句；顿是节奏之断而非糊涂。
