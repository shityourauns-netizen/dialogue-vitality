# 旁白活性修复语料库（Narration Vitality）

旁白（叙述者声音）与人物台词是两种不同用途的语言。**台词 = 人在说话（边想边说）**，**旁白 = 叙述者在讲述（组织信息、承载情绪、与画面互补）**。两者共享本技能的底层铁律（明确主语、不要金句、抑扬顿挫、活灵活现），但活化层不同：台词注入五层口语标记（M1–M5），旁白**不**注入"那个…就是…额"的说话人犹豫标记（除非是第一人称内心独白），核心在"去说明腔、强画面感、排情绪节奏"。

> 本文件是旁白活化的细节库；主流程与精简手法见 [SKILL.md](../SKILL.md) 的「旁白活化（N1–N6）」与「先判断语言用途」。

## 一、旁白死法详表

| 旁白死法 | 表现 | 活化方向 |
|---|---|---|
| 画面复述癖 | 把观众已看见的动作逐条写成"师傅拿起旧伞，打开伞，修理伞骨" | 声画互补：写画外信息/情绪/主题，给画面留白（N1） |
| 说明流水账 | 时间线平铺、无主次、像说明书 | 抓重点、长短句交错、给情绪留位（N2/N6） |
| 形容词堆砌 | "专业、优质、卓越"连续抽象形容代替具体 | 用可感知的具体动作/细节代替（N2） |
| 书面说明腔 | 半文半白、长定语、被动句、说明性定语 | 回口语化叙述（仍是叙述者声音，不是人物口语）（N3） |
| 旁白升华/金句 | "人生最重要的就是…""时光啊…"突然掉书袋 | 删，换成具体情绪或留白（N5） |
| 旁白单调 | 全程一个调、信息密度恒定、像播音 | 抑扬顿挫：长短句、情绪起伏、重点句加重（N6） |

## 二、旁白活化手法（N1–N6）展开

**N1 声画互补（去画面复述）**：旁白补"画面不能直接说的"——情绪、潜台词、时间跨度、画外信息。不重复观众已看见的动作。原："师傅拿起旧伞，打开伞，修理伞骨，修完递给顾客。"→改："这把伞，还想陪他走一段。找到坏掉的地方，再把它修好。"（给现场声留白，删除重复画面的动词）。

**N2 动词驱动 + 画面感（活灵活现）**：用具体动词和可感知细节代替抽象形容与连续形容词。原："我们的服务专业、优质、卓越。"→删；"找到坏掉的地方，再把它修好"用动作落地。

**N3 去书面说明腔**：回口语化叙述，但保持叙述者身份（不是人物口语、不加"那个…就是…"）。原："他对于这件事，是持着一种比较复杂的态度。"→改："这事，他心里其实挺复杂。"（仍像叙述者在讲，不是角色说话）。

**N4 主题与情绪节奏**：每段旁白有清晰的情绪任务（紧张/怅惘/轻快/压抑），情绪通过选择而非标语表达。

**N5 明确主语 + 不要金句**：动作主体清楚；删一切升华/鸡汤/哲理旁白。

**N6 抑扬顿挫（旁白也要起伏）**：长短句交错、信息密度有起伏、情绪有高低，不能平平念稿。用 抑·扬·顿·挫 标注。

## 三、关键边界：旁白 vs 台词

- **台词（人物对白）**：注入五层口语标记（M1–M5）——人在边想边说。
- **旁白（第三人称叙述）**：**不**注入说话人犹豫标记；核心在去说明腔、画面感、情绪节奏、抑扬顿挫。把台词那套"那个…就是…额"硬塞进旁白会人格分裂。
- **第一人称内心独白 / 第一人称叙述**：介于两者之间，可轻量借用 M1–M5（因为是"人物在心里说"），但密度低于对白。判断标准：是不是"某个人在发声"。是→可用口语标记；否（纯客观叙述者）→不用。

## 四、声画互补原则（借用配音打磨方法论）

给每句旁白标：画面已知 / 语言新增 / 需同步动作。旁白可重复关键信息以利理解，但视觉与语言不要同时抛出两个新概念。静音版以必要字幕+动作承接；有声版允许情绪与现场声提供增量。

## 五、before/after 案例（含抑扬顿挫标注）

**案例 A｜画面复述癖 → 声画互补 + 情绪**
> 原（旁白）：夜色中，林晚走进房间，她关上门，走到窗边，拉开窗帘，望着外面的雨。
> 改：林晚进门，没开灯。她站在窗边，看了一会儿雨。屋里就剩雨声了。
> 备注（抑扬顿挫）：抑为主（安静、低能量），末句顿（留白）。删"夜色中/望着"等说明腔，动作保留但提纯，给氛围留白。

**案例 B｜旁白升华/金句 → 具体情绪**
> 原（旁白）：时间会带走一切，但有些东西永远留在心里。她想起从前。
> 改：后来很多事都淡了。可那一晚，她一直记着。
> 备注（抑扬顿挫）：抑+顿（怅惘、慢），删"时间会带走一切"金句，换成具体"那一晚"。

**案例 C｜书面说明腔 → 口语化叙述**
> 原（旁白）：对于这场突如其来的变故，在场的所有人都陷入了沉默之中。
> 改：这变故来得太突然，屋里一下没人说话了。
> 备注（抑扬顿挫）：顿（静场重量），去"对于…之中"书面腔，主语"屋里/人"清楚。

**案例 D｜第一人称内心独白（可轻量用口语标记）**
> 原（独白）：我不知道该怎么办。我感到十分困惑和不安。
> 改：我……我真不知道该怎么办了。怎么说呢，就是，心里特没底。
> 备注（抑扬顿挫）：顿+挫（"我……"卡壳、"怎么说呢"拐弯），因是第一人称发声，可轻量借用 M1–M5。

**案例 E｜形容词堆砌 → 动词驱动**
> 原（旁白）：他神情疲惫而沮丧，缓慢地、无比沉重地坐了下来。
> 改：他整个人垮了，拖着步子，往椅子上一瘫。
> 备注（抑扬顿挫）：顿（重量）+ 抑（低能量），删"疲惫而沮丧/无比沉重"形容词堆砌，用"垮/拖/瘫"动作落地。
