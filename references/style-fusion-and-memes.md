## 一、四种表演感：怎么写进台词

### 相声感（俏、逗、翻）
来源：垫话（闲扯开场）→ 瓢把儿（绕回正题）→ 正活 → 底；三翻四抖（同一事铺三遍、每次微调，第四遍反转点破）；逗哏铺、捧哏翻（一头沉＝一人多一人少；子母哏＝争辩相当）；夸张、重复、对比、误会、反语、曲解；"学"＝模仿对方/第三人语气制造反差。

| 技术 | 写进台词的做法 | 示例 |
|---|---|---|
| 三翻四抖 | 同一件小事铺垫三次、每次加料，第四次反转 | "你说你没去——上回你也说没去，上上回也说没去，这次……监控拍得清清楚楚。" |
| 逗捧接话 | 双人戏：一个推进，一个接话翻面/递话 | A：我跟你说这老板离谱。 B：哎，何止离谱。 |
| 夸张重复 | 把小事放大、关键动作重复 | "你你你……你非要这样是吧。" |
| 闲扯绕回 | 先扯两句闲篇再入正事（垫话→瓢把儿） | "哎今天天儿真不错啊……对了，咱刚说到哪了？哦对，那钱。" |
| 模仿反差 | 学对方/第三人腔调 | "（学对方）'我没事我真的没事'——你都这样了还没事？" |

### 话剧感（厚、藏、性格）
来源：潜台词（话里有话，没说出口的才是戏）；静场（停顿留白，比台词重）；重音节奏（短句爆发、长句拖尾）；语言即性格（每人语言是人格外化）；动作即台词（用动作承载，不干说）。

| 技术 | 写进台词的做法 | 示例 |
|---|---|---|
| 潜台词 | 不说破，用半句/反话/答非所问承载 | "你回来啦。"（本意：你终于舍得回来了。） |
| 静场 | 用省略号/动作留白，不硬写"他沉默了" | "（良久）……你走吧。" |
| 重音节奏 | 激动时短句连发；失落时长句拖尾 | 短："你疯了？谁让你动的？说啊！" 长："行吧。反正……也没人在乎。" |
| 性格化 | 语言是人格外化（同角色分化） | 见 dialogue-vitality-bank.md 模板 |

### 吵架感（烈、赶、翻）
来源：话赶话（一句接一句不让说完）；抢话打断（半句截）；反问连发；翻旧账；人身/口不择言（上头说不该说的）；重复升调（越说越急）；情绪拐点（突然软/哭/沉默）。

| 技术 | 写进台词的做法 | 示例 |
|---|---|---|
| 话赶话 | 逻辑跳跃、不接上句、自顾自说 | "你还有理了？我有理？你先看看你——" |
| 抢断 | 半句截掉 | A：我跟你讲—— B：别讲了！ |
| 反问连发 | 质问式短句 | "你以为呢？我难道没说过？你聋了？" |
| 翻旧账 | 扯出陈年旧事 | "上次也是这样！上上次也是！你从来——" |
| 情绪拐点 | 突然软/哭/沉默 | "我……算了。你爱怎样怎样。"（声音突然低下去） |

### 脱口秀感（碎、接地、callback）
来源：铺垫—停顿—爆发（先铺，卡壳，再炸）；自嘲（拿自己开涮拉近距离）；绝对接地气口语；callback（后文呼应前文梗/词）；预期违背（说一半拐弯）；方言/口语化重构。

| 技术 | 写进台词的做法 | 示例 |
|---|---|---|
| 铺垫-停顿-爆发 | 先铺再卡壳再炸 | "我那天特认真跟他说……（停顿）然后他回我一句'啊？'" |
| 自嘲 | 调侃自己 | "我这个人吧，运气向来稳定——稳定地倒霉。" |
| callback | 后文呼应前文 | 前："我就一普通老百姓。" 后："咱普通老百姓又来了啊。" |
| 预期违背 | 说一半拐弯 | "我以为他会道歉，结果——他问我借钱。" |
| 口语化重构 | 坚决不用书面语 | "这事吧，闹心。"（非"此事令人困扰"） |

## 二、五层标记叠加示范

一句话里同时承载五层（注意：这是"浓"的示范，日常不必每句这么满，但说明各层位置）：

> "那个……额，就是，我跟你说，这事儿吧，我真没辙了，哎。"

拆解：
- 填充词：那个、额（填补停顿、争取时间）
- 犹豫标记：额……就是……（想词、组织）
- 话语标记：就是、吧（回锚重述、句尾软化）
- 口头禅：我跟你说（此人的习惯性起手）
- 停顿词/语气词：哎（句首叹词，无奈）

更日常的"轻"版（推荐多数句子用这种密度）：
> "我查了两天。那个柜子，最后在港口仓库露过面，凌晨三点。然后呢，然后就没了。"

## 三、网梗词库（示例 + 思路）

**用户指定示例（务必保留可用）：**
- 敷衍顺从：对对对，你说的都对
- 懵圈/脱线：不是 / 这给我干哪来了？ / 我是谁我在哪
- 突兀抛梗：你喝过百事可乐么？

**按情境扩展（注意：网梗老化极快，下面只是"类型"示范，实际用时换成当下活的梗）：**
| 类型 | 功能 | 示例词（会过时，仅作思路） |
|---|---|---|
| 嘴硬/否认 | 先反驳再软下来 | 不是、我没有、你别瞎说 |
| 摆烂/认命 | 放弃挣扎 | 算了吧、随缘、就这样吧 |
| 懵圈 | 思绪断线 | 啊？、我是谁、给我干哪来了 |
| 敷衍顺应 | 不想争了 | 对对对、行行行、你说的都对 |
| 突兀抛梗 | 打断严肃、制造反差 | 你喝过百事可乐么、退退退 |
| 自我吐槽 | 脱口秀式自嘲 | 我真是服了、我这个人就这样 |

**使用红线**：梗是调味料，硬塞显假。先问三句——这人会不会这么说话？此刻情境配不配？是不是为了塞梗而塞梗？三个"否"里有一个就别用。

## 四、明确主语 vs 口语省略的边界

用户要"明确主语"，但真人说话本就省略。边界这样划：

**可以省（节奏性省略，上下文清楚）：**
- 同主语延续："（我）没看见啊。" "（你）别去了。"
- 问答链里承前："——吃了吗？""（我）吃了。"

**必须补回（含糊性省略，谁说谁做看不懂）：**
- 跨话轮后主语切换没交代："然后拿了东西就走。"（谁拿？补"他拿了"。）
- 动作+台词主语不清："放下碗，说吃饱了。"（谁？补"老陈放下碗，说吃饱了。"）
- 多个"他/她"堆一起："他说她让他去，她不肯。"（改具体名字或"老陈说秀秀让他去，秀秀不肯。"）

**铁则**：省略只为节奏和真实感，不为制造糊涂。一眼看不懂的，补回主语。

## 五、抑扬顿挫 × 四风格（节奏怎么分配）

四种表演感天然对应不同节奏维度。揉在一起时按这个倾向分配，并**故意插入相反维度破单调**：

| 风格 | 主导节奏维度 | 在台词里的节奏特征 |
|---|---|---|
| 相声 | 挫 + 顿 | 铺垫时顿（卡壳、绕），抖包袱时挫（反转、拐弯）；逗捧交替制造扬抑 |
| 话剧 | 抑 + 顿 | 潜台词靠抑（收着说）和顿（静场留白）承载；重音靠扬点破 |
| 吵架 | 扬 + 顿 | 扬（短句爆发、反问连发）为主，顿（抢断、半句截）穿插；情绪拐点从扬骤降到抑 |
| 脱口秀 | 顿 + 挫（+扬收尾） | 铺垫—停顿（顿）—爆发（挫/扬）；自嘲常走抑，callback 靠挫呼应前文 |

**实操口诀**：写一段对白前先想"这段整体偏哪味"，再故意插相反维度——吵架戏里插一句抑（突然软/哭），相声段子插一句顿（冷场反差），话剧静场插一句扬（爆发）。单调 = 死。

**边界**：扬是情绪/音量的"放"，不是金句（不与"不要金句"冲突）；顿是节奏的"断"，不是糊涂（停顿不能断到主语丢失，不与"明确主语"冲突）。
